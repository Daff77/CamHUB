LOCAL DECODER GUIDE

Panduan Decoder Kamera

Jalankan script PowerShell di bawah ini pada dua terminal terpisah agar decoder lokal dapat streaming ke CamHub. Password diinput secara aman via prompt tanpa disimpan di web dashboard.

  • Kamera 1 (Indoor): V380Decoder-Latest · Port HTTP 8080 (LAN IP: 192.168.100.24 · ID: 124095217)
  • Kamera 2 (Garasi): V380Decoder-Fork · Port HTTP 8081 (Cloud Source · ID: 97357757)
  • Kamera 3 (O Kam Pro): Adapter belum dikonfigurasi (menunggu uji protokol).
cd "$HOME\V380Decoder-Latest"

$user1 = Read-Host "Username kamera 1"
$secure1 = Read-Host "Password kamera 1" -AsSecureString
$ptr1 = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secure1)
$pass1 = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($ptr1)

dotnet run --no-build -- `
  --id 124095217 `
  --username $user1 `
  --password $pass1 `
  --ip 192.168.100.24 `
  --port 8800 `
  --source lan `
  --output rtsp `
  --quality sd `
  --enable-api `
  --http-port 8080 `
  --rtsp-port 8554 `
  --debug

[Runtime.InteropServices.Marshal]::ZeroFreeBSTR($ptr1)
Remove-Variable pass1, secure1, user1 -ErrorAction SilentlyContinue
Script membersihkan pointer memori string password ($ptr) dan variabel sensitive setelah dieksekusi.
