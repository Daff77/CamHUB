CamHub Security & Remote Access

Zero-cloud local camera bridge, VPN remote tunneling, and role-based access control.

LAN Isolated · Zero Cloud Credentials
1
V380 Protocol Decoder

V380 cameras stream on local UDP/TCP port 8800. The C# decoder converts raw frames into an MJPEG HTTP stream on ports 8080 and 8081.

dotnet run --project decoders/v380/V380Decoder.csproj -- --id 124095217 --ip 192.168.100.24 --port 8080
2
RTSP Stream Adapter (FFmpeg)

O Kam Pro or RTSP cameras are bridged via ultra-low latency FFmpeg transcoder to port 8082 without cloud dependencies.

ffmpeg -hide_banner -rtsp_transport tcp -i rtsp://192.168.100.6:10554/live/ch0 -f mpjpeg -q:v 3 http://127.0.0.1:8082/stream
3
Secure Remote Access (Ngrok & WireGuard / Tailscale)

CamHUB includes single-tunnel reverse proxy endpoints (/proxy/stream/<cid>). Never open raw RTSP ports to the public internet.

# Start secure Ngrok tunnel to CamHUB (Port 3000) .\scripts\start_ngrok.ps1
